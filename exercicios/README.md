| Disciplina | Pasta | Ambiente |

| DIM0524 — Móveis | [`movel/`](movel/) | [`play.kotlinlang.org`](https://play.kotlinlang.org) |

| DIM0510 — Processos | [`processos/`](processos/) | O próprio GitHub |

## Por que estes ambientes

O **Kotlin Playground** é oficial, gratuito e não exige cadastro. Isso importa num
laboratório: ninguém fica parado esperando confirmação de e-mail.

Desde a [ADR-0001](../docs/decisoes/0001-stacks-e-estrutura.md), as duas disciplinas usam Kotlin,
então o mesmo ambiente serve para as duas — e o exercício de Web II é o **mesmo domínio** que
a api Ktor usa.

> Caso o laboratório bloqueie esses domínios, uma alternativa para Kotlin é
> `kotlinlang.org/docs/kotlin-tour-welcome.html`, que tem editor embutido nas próprias
> páginas.

## A cadeia que este processo torna visível

```
  Decisão (ADR) ──► História ──► Tarefa ──► Commit ──► PR
       ▲                                                │
       └────── revisada quando a realidade contradiz ◄───┘
```

O MUSI existe, do ponto de vista desta disciplina, para mostrar essa cadeia funcionando
num projeto real, com três componentes e três turmas — e não num exemplo de livro.
